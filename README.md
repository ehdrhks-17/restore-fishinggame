# 한쿠아 복원 프로젝트 (Hanqua Revival)

고도 엔진(Godot Engine 4.x)을 기반으로 한 낚시 게임 **한쿠아** 복원 프로젝트입니다.

## 개발 환경 설정 및 실행 방법

1. **Godot Engine 4.x 설치**:
   - [Godot 공식 홈페이지](https://godotengine.org/)에서 **Godot Engine 4.x** (Standard version) 버전을 다운로드합니다.
2. **프로젝트 열기**:
   - Godot 에디터를 실행한 후 `Import` 버튼을 눌러 본 폴더의 `project.godot` 파일을 선택해 불러옵니다.
3. **실행**:
   - 에디터 우측 상단의 `Play` 버튼 (또는 단축키 `F5`)을 눌러 메인 화면을 실행합니다.

## 디렉터리 구조
- `scenes/`: UI 및 게임 내 씬 파일 (.tscn)
- `scripts/`: 게임 로직, 세이브 및 데이터 싱글톤 스크립트 (.gd)
